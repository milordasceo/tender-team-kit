# Комплект для копирования тендерной команды ботов «Тэндер Мэн»

Команда ботов Grok Bot для поставок по госзакупкам 44-ФЗ / 223-ФЗ в Новосибирской области: главный бот «Тэндер Мэн» (сам ищет закупки скриптом tender_finder и ставит документы в очередь скачивания) и три помощника: «Тендер: Документы», «Тендер: Цены», «Тендер: Итоги». Всё общение команды — только на русском.

Конвейер: поиск (главный бот) → очередь на Google Диске «Тендеры/Очередь» → домашний ПК скачивает документы в «Тендеры/<номер>» → «Документы» читают ТЗ и контракт → «Цены» подбирают товар (А и Б) и считают выгоду → главный бот заводит карточку и пишет владельцу → «Итоги» раз в день проверяют победителей. Ни один тендер не доходит до владельца, пока ТЗ и контракт не прочитаны.

## С чего начать
Откройте **[00_ГЛАВНАЯ_ИНСТРУКЦИЯ_КОПИРОВАНИЯ.md](00_ГЛАВНАЯ_ИНСТРУКЦИЯ_КОПИРОВАНИЯ.md)** и передайте её новому главному боту на новом аккаунте Grok Bot: в ней все правила, пошаговая установка (Notion, почта, скрипт, создание помощников, рутины) и полные тексты всех ролей в приложениях.

## Как скачать
- Git: `git clone https://github.com/milordasceo/tender-team-kit.git`
- Без git: кнопка **Code → Download ZIP** на странице репозитория, затем распаковать.
На компьютере бота комплект кладётся в `/workspace/tenders/team_kit/` (см. шаг 1 файла 00).

**Домашний скрипт скачивания документов** в комплект не входит: zakupki.gov.ru недоступен из дата-центров, поэтому файлы закупок скачивает отдельный скрипт на домашнем компьютере владельца (Windows, Google Диск) по заданиям из папки «Тендеры/Очередь». Что он делает и формат заданий — `07_Скрипт_tender_finder.md`, §10.

## Только шаблоны
В репозитории нет и не должно быть реальных тендеров, номеров закупок, ФИО, телефонов, e-mail, заказчиков, продавцов и ID Notion — только заглушки. Перед каждым коммитом:
```sh
python3 tools/check_public.py        # 0 — чисто, 1 — список подозрительных строк
```
Подключить как git-хук: `ln -sf ../../tools/check_public.py .git/hooks/pre-commit`. Рабочие файлы (`dev/`, `cache/`, `out/`, отчёты, `notion.md`, реальные образцы API) отсекает `.gitignore`.
Исключение — `api/fz44.yaml`, `api/fz223.yaml`: официальная спецификация ГосПлан с примерами самого ГосПлан (не наши тендеры), проверка их пропускает.

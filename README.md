# Комплект для копирования тендерной команды ботов «Тэндер Мэн»

Команда ботов Grok Bot для поставок по госзакупкам 44-ФЗ / 223-ФЗ в Новосибирской области: главный бот «Тэндер Мэн» и помощники «Тендер: Поиск», «Тендер: Цены», «Тендер: Документы». Всё общение команды — только на русском.

## С чего начать
Откройте **[00_ГЛАВНАЯ_ИНСТРУКЦИЯ_КОПИРОВАНИЯ.md](00_ГЛАВНАЯ_ИНСТРУКЦИЯ_КОПИРОВАНИЯ.md)** и передайте её новому главному боту на новом аккаунте Grok Bot: в ней все правила, пошаговая установка (Notion, почта, скрипт, создание помощников, рутины) и полные тексты всех ролей в приложениях.

## Как скачать
- Git: `git clone https://github.com/milordasceo/tender-team-kit.git`
- Без git: кнопка **Code → Download ZIP** на странице репозитория, затем распаковать.
На компьютере бота комплект кладётся в `/workspace/tenders/team_kit/` (см. шаг 1 файла 00).

## Состав
| Файл | Что внутри |
|---|---|
| `00_ГЛАВНАЯ_ИНСТРУКЦИЯ_КОПИРОВАНИЯ.md` | главная инструкция (самодостаточная) |
| `01_Тэндер_Мэн.md` | роль главного бота |
| `02_Поиск.md`, `03_Цены.md`, `04_Документы.md` | роли помощников |
| `05_Notion_CRM.md` | схема и правила CRM в Notion |
| `06_Рутины.md` | расписания и тексты рутин |
| `07_Скрипт_tender_finder.md` | установка, запуск, «если скрипт сломался» |
| `descriptions.json` | имена и описания ботов для CreateAgent |
| `tender_finder/` | скрипт поиска закупок (Python, только стандартная библиотека) |
| `api/` | спецификация GosPlan API (fz44.yaml, fz223.yaml) и черновик fetch.py |

Ключи и пароли в репозитории не хранятся: ключ GosPlan задаётся переменной окружения `GOSPLAN_KEY`.
